# Later

- **Meal plan**: recipes on days, with a yield per day.
- **Grocery list**: from the meal plan, items added up ([recipe.md](recipe.md), rule 3), grouped by aisle. Ticking items off syncs live.
- **Cooking log**: "cooked on 12 Oct, next time less sugar". Notes per cooking, not per revision.
- **Web page import in the app**, without Claude. Recipe rule 3 then needs an answer for ingredient lines the app can't match to an item.
- **Photo import in the app**: on-device text recognition, then the same path as Claude's.
- **Splits and overrides in the app editor** ([adding-recipes.md](adding-recipes.md), rule 3).
- **Editing offline**: queue revisions, resolve conflicts ([revising-recipes.md](revising-recipes.md), rule 2) on reconnect.
- **Vessel scaling**: 26 cm → 20 cm Springform, from the yield's vessel ([recipe.md](recipe.md), rule 9).
- **Volume to mass**: "1 cup Mehl" in g, from a density per item ([cooking.md](cooking.md), rule 8).
- **Translating a recipe**: item names and steps in another language. Until then Claude translates in chat or adds a translated copy.
- **Sharing**: send a recipe to another cook, or share a collection.
- **"Claude is editing …"**: live presence while Claude works on a recipe. Not stored, not replayed.
- **Per-device connections**: one client per install, so the account page lists and disconnects each device ([account.md](account.md), rule 8).
- **Background sync**: silent push so a device is current before it's opened.
- **Watch**: cook mode timers on the Apple Watch.
- **Nutrition** per serving from items.
- **Account recovery** by e-mail ([account.md](account.md)).
